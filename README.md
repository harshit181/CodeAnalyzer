# Java Code Analyzer

A command-line application for analyzing Java source code and generating test request objects.

## Features

- Parse and analyze Java application source code
- Identify methods in the analyzed application
- Generate test request objects for specified methods
- Cover different scenarios present in the method logic
- Display analysis results in a clear format

## Requirements

- Java JDK 11 or higher
- Gradle 7.0 or higher

./gradlew build
